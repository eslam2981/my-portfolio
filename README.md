# Eslam Gamil — Frontend Developer & Creative Technologist

An editorial, high-performance portfolio crafted with **React 19**, **Tailwind CSS v4**, and **Vite**. Built with clean architecture, verified responsive design across all viewports (from 320px mobile to 4K desktop), and accessible UI components.

![Portfolio Preview](public/favicon.svg)

---

## ⚡ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (Pure CSS-first configuration)
- **Routing:** React Router v7 (`BrowserRouter`)
- **Icons:** Lucide React
- **Architecture:** Clean Modular Component Architecture + Custom Hooks
- **Typography:** Plus Jakarta Sans & JetBrains Mono

---

## 🚀 Key Features

- **100% Fully Responsive:** Extensively tested across all form factors (320px mobile, iPhone SE, tablets, laptops, and ultra-wide displays).
- **Smooth Interaction Design:** Hardware-accelerated animations, buttery-smooth hamburger menu with spring physics, and CSS grid accordion transitions.
- **Custom React Hooks:**
  - `useScrollSpy`: Active navigation tracking based on scroll threshold.
  - `useEscapeKey`: Universal keyboard dismiss accessibility for dialogs and modals.
  - `useIntroTimer`: Welcome intro lifecycle, countdown progress, and exit transitions.
- **Interactive Component Lab:** Live optimistic UI mutation preview mimicking TanStack Query v5 patterns.
- **Modular Project Showcase:** Decomposed cards, micro-specs, and full technical case study modals.
- **SEO & Accessibility:** Open Graph metadata, semantic HTML5, aria-labels, and full keyboard navigation.

## 🛠️ Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/eslam2981/my-portfolio.git
cd my-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
